# Montemor-o-Velho — Portugal

Projeto de um site turístico dedicado à vila de Montemor-o-Velho, localizada em Portugal.

## Sobre o projeto

Este site foi desenvolvido durante minha estadia em Portugal e representa um dos meus primeiros contatos com o desenvolvimento web.

A proposta era apresentar Montemor-o-Velho aos visitantes, destacando sua história, patrimônio cultural, gastronomia e experiências turísticas.

O projeto reúne oito páginas com informações sobre a região:

- Página inicial
- História
- Castelo de Montemor-o-Velho
- Arroz-doce
- Lampreia
- Queijadas
- O que fazer
- Contacto

## Tecnologias utilizadas

- HTML5
- CSS3
- Bootstrap 5.3.2
